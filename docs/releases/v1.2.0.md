Update RommPS and open it once. It updates everything else.

### New

- Saves come down as soon as a game finishes downloading, so it's ready to play.
- Save states only come down to an emulator that can load them.
- Save sync is optional. Use RomM just for games, or pick per platform: saves and states, saves only, or off.
- Home has Conflicts, Activity (what synced and why) and Tracked saves. Each game has its own saves view, with restore.
- Settings > Emulators is organized by platform: its emulator, folders, save sync and settings in one place.
- GameCube saves keep the form RomM has them in: a zip, a single .gci, or a whole memory card. Other saves on a card are left alone.
- Porpoise is supported, including its save states. SwanStationPS5 and PS5NES are offered too.
- Settings > Diagnostic bundle, for bug reports and troubleshooting.
- Hold Options to close RommPS gracefully, avoiding any weird behaviors that you often see when hard closing homebrew apps.

### Fixed

- A save or state deleted from the console comes back from RomM.
- Older saves from before RomM's save slots now reach the console.
- A blank PS1 memory card from RomM never replaces one with saves on it.
- Games in folders download with their file names.
- Notifications say what moved and for which games, and every download says when it's done.

### Good to know

- RomM's web player and the PS5 emulators don't always use the same core. A state only comes down where it can load.
