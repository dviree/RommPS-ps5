Another significant update packing a plethora of features. I've spent a good amount of time optimizing connection handling as well as loading of covers and information, especially for larger libraries. This update also brings significant overhaul of save sync support for those consoles that are a bit more involved, like the Switch and 3DS.

### New

- RomM collections support.
- Native notifications support.
- Direct emulator profile updates in app, no more waiting for a new app version.
- Proper PS2 per-game memory card support. Thanks to herobeniyoutube.
- Additional animations during library and cover loading.
- Different versions, discs, update files, or DLCs are now properly shown under a single game and individually downloadable.
- Additional game information displayed in details view.
- Emulator support: GBCXY (Game Boy / Color), Mupen64Plus PS5, Snes9x PS5, Genesis Plus GX PS5, Beetle PCE PS5, FBNeo PS5, PSP5, Crux2, Seedee5, and PS5-ECAM
- Fixed: PSP games that install data to the memory stick no longer fail to sync.
- PS2 per-game saves corrected and syncing as expected. ([#32](https://github.com/s0liton/RommPS/issues/32))

### Fixed

- DS saves sync in PS5CEMU-HAR ([#30](https://github.com/s0liton/RommPS/issues/30)).
- Multiple emulators per game platform are now mounted instead of copied.
- Resting the console with a game open no longer counts as closing it.
- Covers stay on screen when a game is downloaded or removed.
- PS4: less memory used with big emulator setups.
- Renamed game consoles in settings to reflect their proper brand names.

### Good to know

- Pair RommPS with RomM again to see collections. RommPS tells you when.
- Switch saves sync for one Switch user per emulator, the one mapped to the first PS5 user.
- Xbox saves move only while XPSemu is closed.
- Crux2 and CD-i save states only load in the emulator that made them.
