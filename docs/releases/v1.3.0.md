Update RommPS and open it once. It updates everything else.

### New

- Extra emulators no longer get their own copy of every game. Their games folder is mounted from the system's main emulator while they run (PSSwanStation, PSXS5, SwanStationPS5), and the old copies are removed.
- Groundwork for keeping all your games, saves and states in one RommPS folder, mounted into every emulator.
- Changing a system's main emulator moves its RomM games to the new one. If other games are in the old one's folder, RommPS asks what to do with them.
- BIOS files sync from RomM to every emulator that needs them, with the name each one expects. PS2 emulators get a single BIOS. Your own BIOS files are never replaced.
- Shared memory cards (PS2, Dreamcast) now sync both ways between your consoles. Each system uses either shared cards or one card per game.
- New emulators: PS64 (C64), PSSwanStation, PSFlyCast (Dreamcast), Seedee5 (CD-i), XPSemu (Xbox), PS5CEMU-HAR (Wii U, 3DS, DS) and ProsperoEden (Switch).
- Switch games download with their latest update and DLC, into the folders ProsperoEden reads. Each game gets one card in the library, and its details show the title ID of the game, its update and each DLC.
- New saves that sync: Wii U and 3DS (with 3DS save states), Dreamcast VMUs in PSFlyCast and RetroArch's Flycast core, Beetle Saturn cartridge saves and SwanStation .mcd cards.
- RetroArch recognizes 14 more systems, including 3DS, Jaguar, 3DO, PC-FX and Neo Geo CD.
- Redesigned connection handling: RommPS keeps its connections to RomM open instead of opening a new one for every cover and page, so it's much lighter on your server. When RomM stops answering, RommPS says so and waits instead of retrying over and over.
- Downloads cut off halfway carry on where they stopped, and ones that failed while RomM was away start again once it's back. Failed or cancelled downloads can be retried from the Queue.
- Emulators installed after setup are announced once. Turn them on in Emulator Settings.
- Archived games (.rar, or any archive for Switch) aren't downloaded. RommPS asks you to unpack them on the server.
- The Downloads tab is now Queue. A new Downloads tab lists the games on the console and replaces the library's "On this console" row. Same in the web UI.
- Game details show the rating, and button hints stay readable over any cover.
- Activity shows BIOS files and moved games.

### PS4

- Works on firmware 13.52 and 14.00.
- New emulators: pSNES, pNES, pGEN, pGBA and pFBN (now with save states), EmuSuNi, DolphinPS4, NPS64, SNESUI, PS4SX2, Resonance and RArch.
- GameCube saves are shared with the PS5. N64 saves are shared between NPS64, EmuSuNi and RetroArch.
- Resonance's memory cards sync.
- When the sync service isn't running, RommPS says why.
- The PS4 app is now called RommPS and installs over the old one.
- The web UI is faster.

### Fixed

- PSXS5 2.0 save states and memory cards sync again.
- Large save states (GameCube) sync both ways.
- PS1 and PS2 game lists with lots of info load again.
- Turning on many emulators at once no longer stops the sync service.
- A game deleted outside RommPS no longer shows as downloaded.
- Each console shows on RomM under its own name.
- Accented letters in names (Pokémon) show as they should, instead of "?".
- A game whose file was moved or renamed on the RomM server says so, instead of a bare HTTP error.
- General fixes and improvements.

### Good to know

- Update all your consoles. A console still on 1.2 can't read Wii saves made with 1.3.
- Shared memory cards become one card on RomM for all your consoles. The first sync keeps the card played last, and a blank card never replaces one with saves. The other stays in your backups.
- RommPS now always starts with the console, and the setting to turn that off is gone.
- Re-run setup wizard moved to Settings > RomM.
- 3DS save states only load in PS5CEMU-HAR.
