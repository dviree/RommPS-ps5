Update RommPS and open it once. It updates everything else.

### New

- Extra emulators no longer need their own copy of every game. An emulator you add next to the main one for a system plays the main one's games directly, and the copies made before are removed. Works with PSSwanStation, PSXS5 and SwanStationPS5. Settings > Emulators shows which ones play without copies.
- Games an extra emulator downloaded while it was the main one move to the new main emulator. If its folder holds games of its own, RommPS asks whether to move or delete them.
- BIOS files sync from RomM to every emulator that plays the system, in the folder and under the name each one looks for. PCSX2-based emulators get one PS2 BIOS, and the extras left in their folder are removed. Your own BIOS and key files are never replaced.
- Wii U and 3DS saves sync with PS5CEMU-HAR, in the same form as RomM's other clients. 3DS save states are backed up too.
- New emulators: PS64 (Commodore 64), PSSwanStation, PSFlyCast (Dreamcast), Seedee5 (CD-i), XPSemu (Xbox), PS5CEMU-HAR (Wii U, 3DS, DS) and ProsperoEden (Switch).
- PSFlyCast saves sync. Each game's own memory card syncs as its save, and the shared cards are backed up to RomM's memory cards.
- RetroArch's Flycast core: with Per-Game VMUs on, each game's VMU syncs; otherwise its shared VMUs do. Beetle Saturn's cartridge saves and SwanStation's .mcd cards sync too.
- Shared memory cards (PS2, Dreamcast) now sync both ways between your consoles, instead of being backed up only. A system uses either shared cards or one card per game, never both: Settings > Configure Emulators shows which.
- PS4: Resonance's memory cards sync, as on PSFlyCast.
- RetroArch: 3DS, Jaguar, 3DO, PC-FX, Neo Geo CD and 9 more systems are recognized.
- Activity lists BIOS files and moved games.

### PS4: catching up with 1.2.1

- Works on firmware 13.52 and 14.00.
- Finds and syncs more emulators: pSNES, pNES, pGEN, pGBA and pFBN (now with save states), EmuSuNi, DolphinPS4, NPS64, SNESUI, PS4SX2 (memory card backup), Resonance (save states) and RArch.
- GameCube saves are shared with the PS5. N64 saves are shared between NPS64, EmuSuNi and RetroArch.
- When the sync service isn't running, RommPS says why: never started, not in GoldHEN's AutoRun queue, stopped with an error, or its port is taken.
- The PS4 app is now called RommPS, and installs as an update over the previous one.
- The web UI is faster on the PS4.

### Fixed

- PSXS5 2.0's Automatic core is Beetle: its save states and memory cards sync again.
- Large save states (GameCube's run to tens of MB) sync both ways.
- Game lists with a lot of metadata (PS1, PS2) load.
- Turning on many emulators at once no longer stops the sync service.
- The BIOS button no longer fails on files RomM lists but doesn't have.
- A game deleted outside RommPS no longer shows as downloaded. It can be downloaded again.
- Covers that failed to load once (RomM busy) are tried again instead of staying blank.
- Consoles show on RomM under their own name (Console Name in the system settings), not "PlayStation 5". A PS4 no longer shares its save states' names with a PS5. A name set in the web UI still wins.

### Good to know

- Shared memory cards move to one card on RomM for every console. The first sync after updating keeps whichever card is newer; the other stays in RommPS's backups and in RomM's card history.
- Settings: clearer names, and Re-run setup wizard is now under RomM.
- RommPS always starts with the console. The switch to turn that off is gone, and autostart that another tool turned off comes back on.
- Wii saves now go up in the form RomM's other clients use. Each one uploads once after updating.
- 3DS save states only load in PS5CEMU-HAR, the build that made them.
